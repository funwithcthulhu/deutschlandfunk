# Screenshots

Screenshots are useful for releases, bug reports, and documentation updates.
Do not include LingQ tokens, passwords, private account details, or private
local paths in screenshots.

## Suggested Release Screenshots

- Browse page with a public section selected and no private settings visible.
- Library + LingQ page showing upload states, with account details hidden.
- Audio page showing the Health panel and local actions.
- Installer welcome screen showing `DLF LingQ Reader`.

## Bug Report Screenshots

When reporting UI behavior, capture:

- The visible status message.
- The selected page and filters.
- The affected row, if the issue is article-specific.
- The Health panel if the problem is database, backup, or diagnostics related.

Prefer exporting a diagnostics bundle for support details instead of capturing
settings screens that may contain private paths.
